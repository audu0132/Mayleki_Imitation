# 💎 Mayleki Imitation Jewellery

A premium luxury jewellery rental and shopping platform built with the MERN Stack, designed to provide a seamless experience for customers looking to **rent, buy, or explore premium 1GM and imitation jewellery** for weddings and special occasions.

---

## ✨ Features

### 👩 Customer Features

- Browse premium jewellery collections
- Search and filter products
- Product detail page
- Wishlist management
- Shopping Cart
- Rental Booking
- Secure Checkout
- User Authentication
- Order History
- Profile Management
- Contact & Inquiry Form

---

### 👑 Admin Features

- Admin Dashboard
- Product Management
- Category Management
- Order Management
- Customer Management
- Rental Booking Management

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/audu0132/Mayleki_Imitation.git
```

Move into project

```bash
cd Mayleki_Imitation
```

---

## Backend Setup

```bash
cd backend
npm install
```

Create

```
.env
```

Example

```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret

CLOUDINARY_CLOUD_NAME=xxxx

CLOUDINARY_API_KEY=xxxx

CLOUDINARY_API_SECRET=xxxx
```

Run Backend

```bash
npm run dev
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Build

```bash
npm run build
```
