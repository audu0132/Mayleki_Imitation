# Mayleki Database Schema & Collections

### Core Models
- **Users**: Authentication, addresses, role-based access (admin, customer, stylist).
- **Products**: Jewellery specifications, 1GM gold purity flags, high-res gallery, rental daily prices.
- **Orders**: Rental orders, security deposit status, shipment tracking, return verification.
- **Reviews**: Verified customer ratings, wedding occasion tags, moderation state.
- **SupportTickets**: Customer concierge inquiries and deposit refund lifecycles.
- **AuditLog**: Admin mutations and sensitive activity monitoring with 90-day retention.
