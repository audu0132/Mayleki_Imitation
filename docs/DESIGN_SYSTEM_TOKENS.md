# Mayleki Luxury Design System Tokens

All styling tokens are organized under `frontend/src/styles/tokens/`:
- `colors.js`: Palette definitions
- `typography.js`: Font sizes, line heights, and serif weights
- `gradients.js`: Regal gold shimmer and dark velvet background gradients
- `shadows.js`: Soft glowing box-shadows
- `spacing.js`: Container and section margins
